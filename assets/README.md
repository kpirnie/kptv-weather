# assets

Everything here is optional. The channel draws its icons procedurally and
falls back to a built-in face when no fonts are present.

    logo.png            header logo, scaled to the header band
    fonts/              Inter TrueType faces, or any .ttf
    icons/<name>.png    overrides a drawn icon

Icon names: clear-day, clear-night, partly-cloudy-day, partly-cloudy-night,
cloudy, rain, snow, fog, wind, thunderstorm.

Fonts are looked for in this order: Inter-Black.ttf, Inter-Bold.ttf,
Inter-SemiBold.ttf, Inter-Medium.ttf, Inter-Regular.ttf. Inter is licensed
under the SIL Open Font License; download it from https://rsms.me/inter/ and
drop the .ttf files in fonts/.
